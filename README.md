#Key Features

Dynamic "Pokai" Trajectory: Calculates remaining days before funds run out in real time and automatically adjusts recommended daily spending limits.
Income & Expense Tracking: Differentiates incoming allowances/income from subcategorised spending (Food & Drink, Transportation, Yuran, Entertainment, Groceries, etc.).
Budget Management: Editable total monthly budget cap that dynamically adjusts alongside incoming allowance/cash flow.
Visual Analytics: Interactive line charts powered by Chart.js displaying daily balance movements across the active month.
Spending Insights: Automatic calculations highlighting top spending categories as well as highest and lowest single expenses.
Malaysia Timezone (MYT):** Fully synchronised to UTC+8 for precise local transaction timestamps.

#Tech Stack

Backend Framework: Python 3, Flask, Flask-SQLAlchemy
Database & ORM: PostgreSQL (Supabase) with SQLAlchemy ORM
Authentication: Passlib / Werkzeug Security (`scrypt` password hashing)
Frontend: HTML5, Tailwind CSS, JavaScript (ES6), Chart.js
Deployment Platform: Render (PaaS)
